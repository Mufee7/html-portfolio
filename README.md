# HTML Portfolio — Early Learning Project

My first HTML portfolio, created while learning the fundamentals of web development.

## Contents

- Movie ranking page
- Birthday invitation page
- About and contact pages
- Image previews linking to the project pages

## View locally

Clone or download this repository, then open `index.html` in a browser. No dependencies or build tools are required.

## What this project demonstrates

Basic HTML page structure, headings, images, relative file paths, and navigation between pages.
